# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-02

### Added
- Initialize Graph Quest project.
- Implement Dijkstra shortest path algorithm.
- Implement BFS pathfinding algorithm.
- Add automated tests for Dijkstra and BFS.
- Add tests for shortest path, unreachable destination, and identical start and end points.
- Add GitHub Issue templates.
- Add Pull Request template.
- Add GitHub Actions CI workflow.
- Add environment configuration example.
- Add dependency management configuration.
